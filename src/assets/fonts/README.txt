Run `scripts/fetch-fonts.sh` from the repo root to populate this directory.

It should end up with 11 files, matching the @font-face rules in src/index.css:
  oswald-500.woff2  oswald-600.woff2  oswald-700.woff2
  inter-400.woff2   inter-500.woff2   inter-600.woff2   inter-700.woff2
  bungee-400.woff2  press-start-2p-400.woff2
  space-grotesk-400.woff2  space-grotesk-700.woff2

These are downloaded, not committed as binaries generated by hand - see the
script for why (no network access in the sandbox this was wired up in).
